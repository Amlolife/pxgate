# Pxgate - Modern Photo Culling Application

A fast, modern photo sorting and culling application with an intuitive interface.

## ✨ Features

- **Fast Photo Sorting** - Quickly cull through hundreds of photos
- **RAW + JPG Support** - Handle both formats seamlessly
- **Modern UI** - Clean, professional interface with blue accent theme
- **Grid View** - See multiple photos at once
- **Keyboard Shortcuts** - Lightning-fast workflow
- **Session Management** - Save and restore your work
- **Cross-Platform** - Works on Windows, macOS, and Linux

## 🚀 Quick Start

### Windows
1. Extract the ZIP file
2. Open the `Pxgate` folder
3. Double-click `Pxgate.exe`

### macOS
1. Open the DMG file (or extract ZIP)
2. Drag `Pxgate.app` to Applications
3. Right-click and select "Open" (first time only)

## ⌨️ Keyboard Shortcuts

- **→ / Space** - Next image
- **← / Backspace** - Previous image
- **X** - Mark for deletion
- **✓** - Mark as keeper
- **G** - Toggle grid view
- **M** - Toggle minimap
- **Ctrl+Z** - Undo
- **Ctrl+Y** - Redo

## 📁 Supported Formats

### Images
- JPG, JPEG
- PNG
- HEIC, HEIF
- BMP, TIFF

### RAW Formats
- Canon (CR2, CR3)
- Nikon (NEF, NRW)
- Sony (ARW)
- Fujifilm (RAF)
- And many more...

## 💡 Tips

1. **Load Images** - Click "Load Images" to start
2. **Quick Sort** - Use X and ✓ keys for rapid sorting
3. **Grid View** - Press G to see multiple photos
4. **Save Sessions** - Save your progress anytime
5. **RAW Linking** - Link JPG previews with RAW files

- **macOS**: 10.13 or later

## 🎯 Workflow Example

1. **Load** your photo folder
2. **Navigate** with arrow keys or click
3. **Mark** keepers (✓) and rejects (X)
4. **Review** in grid mode (G key)
5. **Move** selected photos to folders
6. **Done!** Sorted photos ready to edit
